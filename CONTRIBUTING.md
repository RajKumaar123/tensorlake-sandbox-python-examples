# CONTRIBUTING.md

# Contributing to Tensorlake Sandbox Python Examples

First of all, thank you for taking the time to contribute!

Whether you're fixing a typo, improving documentation, reporting a bug, or adding a new Tensorlake example, your contribution is greatly appreciated.

The goal of this repository is to become a high-quality learning resource for Tensorlake Sandboxes and modern AI engineering.

---

# Project Goals

This repository aims to:

- Learn Tensorlake through hands-on experimentation
- Build production-quality Python examples
- Document engineering discoveries
- Create reusable learning resources
- Support a technical Medium article series
- Help AI engineers build stateful AI systems

Please keep these goals in mind when contributing.

---

# Coding Standards

Please follow these guidelines.

- Python 3.12+
- Follow PEP 8
- Write readable code
- Use meaningful variable names
- Add comments where appropriate
- Add docstrings for reusable functions
- Prefer small, focused examples
- Avoid duplicated code

---

# Documentation Standards

Every new example should include:

- Objective
- Requirements
- Source code
- Execution steps
- Expected output
- Explanation
- Lessons learned

Whenever possible, include screenshots and terminal outputs.

---

# Verification

Do not submit untested code.

Before opening a pull request, verify:

- Code executes successfully
- Output is correct
- Documentation matches implementation
- Errors are handled gracefully

Never assume SDK behavior.

Always verify experimentally.

---

# Git Commit Messages

Use clear commit messages.

Examples:

```
Implemented sandbox creation example

Added snapshot example

Improved package installation example

Updated README

Fixed authentication example
```

Avoid generic messages such as:

```
Update

Changes

Fix

Code
```

---

# Pull Requests

A good pull request should include:

- Clear description
- Purpose of the change
- Related issue (if any)
- Screenshots (if applicable)
- Updated documentation

---

# Reporting Issues

When reporting an issue, include:

- Operating System
- Python Version
- Tensorlake SDK Version
- Steps to reproduce
- Expected behavior
- Actual behavior
- Error messages
- Screenshots (if available)

---

# Feature Requests

Feature requests are welcome.

Examples:

# Code Review Checklist

- Comments are helpful
- Documentation updated
