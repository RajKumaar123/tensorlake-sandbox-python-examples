# Project Vision

The goal of this repository is to become a comprehensive open-source learning resource for Tensorlake Sandboxes.

The project focuses on:

- Learning Tensorlake experimentally
- Building production-quality Python examples
- Documenting engineering discoveries
- Creating reusable learning resources
- Supporting a Medium article series
- Helping AI engineers build stateful AI systems
