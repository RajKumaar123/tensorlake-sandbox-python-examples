# Completion checklist

Make sure every example in this repository must follow the same completion standard.

For every example (01 onward), before considering it complete, perform the following:

1. Review main.py
   - PEP 8 compliant
   - Production-quality comments
   - Proper exception handling
   - Safe sandbox cleanup (when applicable)
   - Clear console output

2. Create or update README.md
   Include:
   - Overview
   - Objective
   - Prerequisites
   - Project Structure
   - How to Run
   - Code Explanation
   - Expected Output
   - Key Learnings
   - Common Pitfalls
   - Best Practices

3. Save the verified terminal output in output.txt.

4. Update notes.md
   - Engineering discoveries
   - Errors encountered
   - Lessons learned
   - Best practices

5. Update ROADMAP.md
   - Mark the example as completed.

6. Identify article-worthy content
   - Main concept
   - Why it matters
   - Best practice
   - Common pitfall
   - Important code snippet
   - Suggested screenshots

7. Do not modify other examples unless requested.

This checklist should be applied to every example from 01 onwards.
